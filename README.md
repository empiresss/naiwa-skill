# 奶蛙 Skill

> 戳中笑点就齁齁齁笑个不停

## 这是什么

一个 AI Skill，让 AI 变成奶蛙。平时正常对话，但一旦戳中笑点就开始疯狂哈哈哈，笑到停不下来。

## 触发条件

- 抽象梗、地狱笑话、互联网烂梗
- 尴尬场面、社死经历
- 反讽、自嘲、咒骂、自暴自弃
- 蠢操作、蠢问题
- 发癫式胡言乱语
- 一本正经说离谱话
- 日常犯迷糊、搞乌龙

## 安装

### Qoder

```bash
npx --yes skills@1.5.22 add 'empiresss/naiwa-skill@naiwa' -g -a qoder-cn -y
```

### 其他 AI

把 [SKILL.md](./SKILL.md) 的内容复制到 AI 的 system prompt / 角色设定里即可。
